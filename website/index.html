安装 Flykey

两分钟，开始用键盘浏览。

商店发布前可以从源码安装开发版。构建产物只包含本地代码，不加载任何远程脚本。

前往 GitHub ↗
  1. 01
    获取源码并构建npm install && npm run build
  2. 02
    打开扩展管理页chrome://extensions
  3. 03
    开启开发者模式

    点击“加载已解压的扩展程序”，选择项目根目录。

  4. 04
    按网站自由启停

    点击工具栏中的 Flykey 图标，使用开关保存当前网站偏好。

Privacy by design

你的浏览历史，
不会成为我们的数据。

Flykey 不含分析 SDK、广告或账号系统。历史搜索和正文提取都在当前设备完成；朗读内容只交给浏览器或操作系统提供的语音功能。
