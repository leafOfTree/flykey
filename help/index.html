Keyboard-first browsing

快捷键与使用帮助

在普通网页上用键盘完成滚动、跳转、搜索和标签页管理。输入框获得焦点时，Flykey 会自动让出按键。

?随时打开本页

先记住这三个

jk滚动页面按住即可连续滚动
f定位链接输入页面上的提示字母
o搜索与打开历史、网址和站点搜索

Command palette

命令面板

  • Enter 在新标签页打开
  • Ctrl/⌘ + Enter 在当前标签页打开
  • 可以直接输入完整网址或 localhost 地址

Per-site control

需要安静时，随时停用

点击 Chrome 工具栏中的 Flykey 图标，可为当前网站长期启用或停用按键映射。停用时，当前标签页的图标会显示小型 off 徽标；设置只保存在浏览器本地。

;临时暂停只影响当前页面，刷新后恢复。

网站开关按域名保存，修改后立即生效。

提示

Chrome 内部页面、Chrome Web Store 等受浏览器保护的页面不允许扩展注入，因此 Flykey 快捷键不会生效。
